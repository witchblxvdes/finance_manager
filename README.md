# Finance Manager

A simple console-based personal finance management application written in Python.

## About the Project

Finance Manager is a command-line application that allows users to track their personal income and expenses.

The application stores transactions, calculates financial statistics, and provides transaction filtering by category.

## Features

- Add income transactions.
- Add expense transactions.
- Display all transactions in a table format.
- Delete transactions by ID.
- Calculate total income.
- Calculate total expenses.
- Calculate current balance.
- Filter transactions by category.
- Automatically generate unique transaction IDs.
- Validate transaction data.
